## 🚀 Start in 3 Easy Steps

### Step 1: Clone & Install (5 min)
```bash
git clone https://github.com/cnoirya/v0-cnoirya-platform-blueprint.git
cd v0-cnoirya-platform-blueprint
npm install
```

### Step 2: Configure Environment (5 min)
```bash
cp .env.example .env.local
# Add Supabase credentials to .env.local
npm run dev
```

### Step 3: Create Admin Account (5 min)
- Sign up at http://localhost:3000/login
- Add `is_admin: true` to user metadata in Supabase
- Access admin panel at http://localhost:3000/admin-login

**Total time: 15 minutes to working platform**
